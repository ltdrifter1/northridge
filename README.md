# Northridge Advisory

Premium financial strategy and Fractional CFO site.

## Stack

- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- React Hook Form + Zod

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Pages

- `/` — Home
- `/about` — About
- `/services` — Services
- `/contact` — Contact (email form)
